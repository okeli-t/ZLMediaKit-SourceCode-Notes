## 完整规划

共 30 篇，分 6 大模块，详见 [ZLMediaKit源码解读专栏规划.md](./ZLMediaKit源码解读专栏规划.md)

## 创作模式

- **人**负责技术方向、内容判断、精修
- **TRAE**负责源码事实校验（Grep/Read 直接查本地 ZLMediaKit 克隆）、规范统一、Mermaid 时序图生成
- 每篇经 3-5 轮逐段审校，已累计修正 >37 处源码事实错误
